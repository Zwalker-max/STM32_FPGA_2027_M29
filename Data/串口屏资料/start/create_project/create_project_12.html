RTC相关

校准RTC时钟

带RTC的型号，背部会有一个纽扣电池座。

使用带RTC功能的屏幕（K0/X5系列或其他定制型号）,时钟是不会自动同步的，需要手动同步时间

1.联机成功时，底部会显示联机成功的信息

2.点击操作-校准设备RTC时钟

RTC电池型号

如果要保证时钟断电后还能继续走，请安装背部的RTC电池，型号为CR1220，电池安装时，有字的一面应朝外
