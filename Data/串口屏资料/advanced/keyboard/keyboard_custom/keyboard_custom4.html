如何让键盘的光标不闪烁

提示

关闭键盘页面的tm0控件使能即可

也可以在页面后初始化事件中判断跳转过来的控件的pw属性（需要文本控件，数字控件不支持pw属性）

完整的代码如下

if(p[loadpageid.val].b[loadcmpid.val].type==116)
{
   if(p[loadpageid.val].b[loadcmpid.val].pw==1)
   {
      tm0.en=0
   }else
   {
      tm0.en=1
   }
}
